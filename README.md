# Catálogo de Videojuegos con React

Aplicación web hecha con React (Vite) para explorar un catálogo de videojuegos, buscar por nombre, filtrar por género, marcar favoritos y ver el detalle de cada juego.

**Demo en línea:** https://dgonav.github.io/catalogo-videojuegos/

## Entregables

- Aplicación desplegada: https://dgonav.github.io/catalogo-videojuegos/
- Video de demostración: https://drive.google.com/file/d/1EjBSeuspTYBlwM3D2uxMQXu0t-IYR5dp/view?usp=sharing
- Explicación (PDF): [entregables/Actividad_10_Catalogo_Videojuegos.pdf](entregables/Actividad_10_Catalogo_Videojuegos.pdf)

## Requisitos

- Node.js 18 o superior (incluye npm)

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio:
   ```bash
   git clone https://github.com/dgonav/catalogo-videojuegos.git
   cd catalogo-videojuegos
   ```
2. Instalar las dependencias:
   ```bash
   npm install
   ```
3. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abrir en el navegador la dirección que muestra la terminal (normalmente http://localhost:5173).
